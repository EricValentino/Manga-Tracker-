# AniTracker

A full-stack manga and anime tracking application with AI-powered recommendations. Search real manga and anime catalogs, track your reading/watching progress, and get personalized recommendations generated by an LLM based on your actual saved list.

## Features

- **Live catalog search** — search manga and anime via the AniList GraphQL API, with real cover art, genres, and descriptions
- **Personal library** — save manga and anime to your list, track chapter/episode progress, reading status, and personal ratings
- **AI-powered recommendations** — sends your saved list to OpenAI, which reasons over your actual reading history to suggest new titles with explanations, enriched with real cover art pulled from AniList
- **Discover pages** — browse trending, top-ranked, and popular manga/manhwa/anime in horizontally scrollable rows
- **Detail view** — click any title to view full synopsis, genres, and score in a modal
- **Full CRUD** — create, read, update, and delete both library entries and progress records

## Tech Stack

**Backend**
- Python, FastAPI
- SQLModel (SQLAlchemy + Pydantic) with SQLite
- httpx for external API calls

**Frontend**
- Vanilla HTML, CSS, JavaScript (no framework)
- GSAP for animations and scroll-triggered effects

**External APIs**
- [AniList](https://anilist.co/) GraphQL API — manga/anime catalog data
- OpenAI API — recommendation generation

## AI Integration

The recommendation engine works by:
1. Pulling the user's saved manga list from the database
2. Formatting it into a prompt describing titles, genres, and reading status
3. Sending it to OpenAI's API with a request for structured JSON output
4. Enriching each recommendation with a real cover image by cross-referencing AniList's search API
5. Returning the combined result to the frontend

## Running Locally

**Prerequisites:** Python 3.9+, an OpenAI API key

```bash
# Clone the repo
git clone https://github.com/EricValentino/Manga-Tracker-.git
cd Manga-Tracker-

# Set up a virtual environment
python3 -m venv venv
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Add your OpenAI API key
echo "OPENAI_API_KEY=your_key_here" > .env

# Run the server
uvicorn main:app --reload
```

Then open `http://127.0.0.1:8000/app` in your browser.
